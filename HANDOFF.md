# Community Hub source handoff

Both ZIPs are required. The source ZIP contains the runnable Astro/TypeScript project, most images, fonts, tests, and documentation. The media ZIP contains the two original hero videos and the individually extracted platform-explanation assets. This is a source handoff, not a published deployment.

## Merge the downloads

1. Put `community-hub-source.zip` and `community-hub-media.zip` in the same new empty folder.
2. Extract BOTH ZIPs into that SAME folder. Each contains the same top-level `community-hub-source/` path, so merge that folder when your extraction app asks. The two ZIPs have no overlapping files. Do not extract the media ZIP inside the already-created `community-hub-source/` folder and do not replace/delete that folder.
3. The result must include `community-hub-source/package.json` and both `community-hub-source/public/assets/hero-ch-fwd.mp4` and `community-hub-source/public/assets/hero-ch-fwd-720.mp4`.
4. Verify the complete clean extraction before installing dependencies: from `community-hub-source/`, run `python3 verify-source.py` (or `py -3 verify-source.py` on Windows). It checks every project file and the exact file set. On macOS/Linux, `shasum -a 256 -c SHA256SUMS` or `sha256sum -c SHA256SUMS` also verifies file bytes.

Command-line extraction on macOS/Linux, from the folder holding both ZIPs:

```sh
unzip community-hub-source.zip
unzip community-hub-media.zip
cd community-hub-source
python3 verify-source.py
```

## Run the site

Use Node 22.12+ and npm 9.6.5+:

```sh
npm ci
npm run check
npm run build
npm run preview -- --port 4327
```

Open http://127.0.0.1:4327/. Use `npm run dev` for development. See `README.md` for tests and optional Python/browser QA dependencies.

## Verification, scope and limits

Read `QA-STATUS.md` for final handoff evidence and limitations, and `docs/refinement-20261002/README.md` for the dated refinement review. Historical reports remain historical. A hash match establishes file integrity, not successful execution or product approval. Do not infer a full browser-suite or physical-device pass from unit, syntax, static contracts, or private-preview spot checks.

The generated build, dependencies, Astro cache, generated test runtime, browser artifacts, Python caches, editor preferences, and local consent/configuration are intentionally omitted. They are regenerated by documented commands. All original public assets and all named additions are included across these two ZIPs. External dashboards, feeds, controllers, and lesson PDFs still depend on their hosts and internet access.

Historical migration parity tests refer to an optional frozen `reference/` tree absent from the supplied archive; it has not been invented. The capture utility can reference historical comparison screenshots outside this source tree; they are not production dependencies. No secret scanner can establish the absence of every possible secret format.

`SOURCE-MANIFEST.json` lists every included project file, its size, SHA-256 and ZIP assignment, plus asset-preservation and exclusion details. `SHA256SUMS` covers project files and handoff metadata other than itself. The separate archive checksum list covers both ZIPs.

## Attention squirrel

A single functional cue that pops out beside something the visitor must act on, then leaves as soon as they start (AGENTS.md allows it; the decorative mascot ban stands).

- Code: `src/scripts/ui/attention-squirrel.ts` (pure decision logic exported, tested in `tests/attention-squirrel.test.mjs`), wired from `base.ts`; styles `src/styles/oct3_squirrel.css` (imported last); art `public/assets/squirrel-cue.webp` + `-still.png`, regenerated by `scripts/make-squirrel-cue.py` (run from the repo root).
- Opt in: `data-squirrel="Text"` and optional `data-squirrel-side="left|right|top"`. Automatic: every `[data-scroll-owner]` that really overflows ("Scroll here") and the `AUTO_TARGETS` list at the top of the module (phone controllers "Try the controller", `.native-choices` pickers "Pick one to explore").
- Rules: shows at 60% in view, visible, 1s idle; one at a time; hides on wheel/touch (scroll regions) or pointerdown/keydown/focus (controllers, pickers), then that target is done for the session (`sessionStorage` key `ch-squirrel-done`). Leaving view hides it without marking done. Clicking the squirrel plays a small demo and counts as done.
- Placement: beside the target edge in free space (right, left, then top), validated against text, media and controls and the header; no room means no cue. Reduced motion: fade only. The target gets `aria-describedby` to a visually hidden hint; the squirrel is `aria-hidden`.
- Debug: `window.__chSquirrel.state() / events() / reset()`.
