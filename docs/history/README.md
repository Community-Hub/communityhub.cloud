# History

These files describe earlier versions of the site and are kept for reference only. None of them is current.

- `2026-10-source-handoff/`: the October 2026 source handoff of the Astro static site, which used to sit at the repository root. `HANDOFF.md` (how to merge the two ZIPs and run the Astro site), `QA-STATUS.md` (the October 2 navigation revision and its checks), `VERIFICATION.md` (the September 30 TypeScript migration), and `SOURCE-MANIFEST.json`, `SHA256SUMS` and `verify-source.py` (checksums of that handoff's files). The checksums no longer match the repository, and `verify-source.py` only works inside an extracted copy of that handoff.
- `AGENTS-2026-10.md`: the agent instructions for the October version. The current `AGENTS.md` keeps the owner's process rules and replaces the visual direction with `DESIGN.md`.

Older documents elsewhere in `docs/` still refer to these files at the repository root.
